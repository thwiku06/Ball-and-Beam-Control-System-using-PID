
# Ball and Beam Control System Using PID

A closed-loop ball-and-beam control prototype developed using Arduino,
an ultrasonic distance sensor, and a servo motor.

The system continuously measures the position of a ball on a beam and
adjusts the beam angle using a PID controller to bring the ball toward
a predefined target position.

## Objective

To demonstrate the practical implementation of feedback control and
PID-based position regulation using low-cost embedded hardware.

## System Architecture

Ultrasonic Sensor
        ↓
Distance Measurement
        ↓
Filtering
        ↓
Error Calculation
        ↓
PID Controller
        ↓
Servo Motor
        ↓
Beam Tilt
        ↓
Ball Position
        ↺
